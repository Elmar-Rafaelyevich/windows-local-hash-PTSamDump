## Что разбирается

Атака, при которой локальный администратор (или malware с правами админа)
копирует два куста реестра Windows и отправляет их наружу:

| Куст | Что содержит | Зачем атакующему |
|---|---|---|
| `HKLM\SAM` | Локальные учётные записи + NT-хэши паролей | Даёт хэши |
| `HKLM\SYSTEM` | Boot key (SysKey) | Расшифровывает SAM |

По отдельности файлы бесполезны — только вместе дают NTLM-хэши,
которые затем используются для **Pass-the-Hash** или крака в hashcat.

## Как выглядит атака (высокоуровнево)

1. **Поднятие прав** — UAC bypass через `ShellExecuteW(..., "runas", ...)`
   или запуск от имени администратора.
2. **Создание дампа реестра**:
3. **Эксфильтрация** — отправка файлов через Telegram Bot API
(`sendDocument`), Discord webhook, HTTP POST на C2 и т.п.
4. **Заметание следов** — перезапись файлов нулями + удаление
(на NTFS **не** уничтожает данные полностью: остаются `$MFT`,
`$LogFile`, теневые копии).

## Артефакты для детекта

| Источник | Признак |
|---|---|
| Sysmon Event ID 1 | `reg.exe` с аргументами `save`, `HKLM\SAM` или `HKLM\SYSTEM` |
| Sysmon Event ID 11 | Создание `*.save` (особенно `sam.save`, `system.save`) в пользовательских папках |
| Sysmon Event ID 3 | Исходящее соединение к `api.telegram.org` / `api.discord.com` с рабочей станции |
| Windows Security 4688 | Процесс `reg.exe` от пользователя, не входящего в группу администраторов |
| Defender for Endpoint | Alert `Credential dumping via registry` |
